Informasi Sistem

Aplikasi ini digunakan untuk mengelola data mahasiswa, termasuk menambahkan, mengedit, dan menghapus informasi mahasiswa. Aplikasi ini juga menyediakan fitur pencarian dan filter untuk memudahkan pengguna dalam menemukan data mahasiswa yang diinginkan.

Fitur Utama

  • Menambahkan data mahasiswa baru
  • Mengedit data mahasiswa yang sudah ada
  • Menghapus data mahasiswa
  • Pencarian dan filter data mahasiswa
